# Actividad 1 — Diferencia entre Arreglos

## Descripción

Actividad práctica desarrollada en Java para trabajar con arreglos y operaciones entre sus elementos.

El programa solicita al usuario dos arreglos de **7 números enteros**. Posteriormente, calcula la diferencia entre los elementos que ocupan la misma posición y almacena los resultados en un tercer arreglo.

Finalmente, calcula el promedio de los valores obtenidos.

## Funcionamiento

El programa realiza los siguientes pasos:

1. Crea tres arreglos de 7 posiciones.
2. Solicita al usuario los valores del primer arreglo.
3. Solicita los valores del segundo arreglo.
4. Calcula la diferencia entre ambos arreglos:

arreglo3[i] = arreglo1[i] - arreglo2[i]

5. Almacena las diferencias en el tercer arreglo.
6. Calcula la suma de las diferencias.
7. Calcula el promedio.
8. Muestra el tercer arreglo y su promedio.

## Conceptos utilizados

* Arreglos (`arrays`)
* Ciclos `for`
* Clase `Scanner`
* Entrada de datos
* Operaciones aritméticas
* Acumuladores
* Conversión de tipos
* Métodos básicos de Java

## Ejecución

Se requiere tener instalado el **JDK de Java**.

Desde la terminal, ubicándose dentro de esta carpeta:

```bash
javac DiferenciaArreglos.java
java DiferenciaArreglos
```

El programa solicitará los 14 números correspondientes a los dos arreglos.

## Aprendizaje

Esta actividad permitió practicar el manejo de arreglos, recorridos mediante ciclos y operaciones entre elementos que ocupan la misma posición en diferentes estructuras.
