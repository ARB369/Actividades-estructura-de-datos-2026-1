# Actividades-estructura-de-datos-2026-1

Repositorio con actividades y proyectos desarrollados durante el curso de Estructuras de Datos, utilizando principalmente **Java**.

El objetivo de este repositorio es documentar mi proceso de aprendizaje y las implementaciones realizadas durante mi formación en Ingeniería de Software y Datos.

## Contenido

### Actividad 1 — Diferencia entre arreglos

Implementación de un programa en Java que trabaja con tres arreglos de números enteros.

El programa:

* Solicita al usuario dos arreglos de 7 números.
* Calcula la diferencia entre los elementos correspondientes de ambos arreglos.
* Almacena los resultados en un tercer arreglo.
* Calcula y muestra el promedio de las diferencias.

**Conceptos trabajados:**

* Arreglos.
* Ciclos `for`.
* Entrada de datos con `Scanner`.
* Operaciones con arreglos.
* Acumuladores.
* Cálculo de promedios.

### Actividad 2 — Implementación de una pila

Implementación de una estructura de datos tipo **pila (Stack)** utilizando un arreglo, además del uso de la clase `Stack` incluida en Java.

El programa:

* Crea una pila con capacidad definida.
* Agrega números aleatorios.
* Consulta el tamaño actual de la pila.
* Elimina elementos mediante la operación `desapilar`.
* Consulta el espacio disponible.
* Utiliza `Stack<Integer>` para invertir el orden de los elementos de otra pila.

**Conceptos trabajados:**

* Estructuras de datos.
* Pilas.
* Arreglos.
* LIFO (Last In, First Out).
* Métodos y clases en Java.
* Generación de números aleatorios.
* Uso de `Stack`.
