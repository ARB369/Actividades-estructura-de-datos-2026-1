# Estructuras de Datos

Repositorio con actividades académicas desarrolladas durante el curso de **Estructuras de Datos**, utilizando principalmente **Java**.

El objetivo de este repositorio es documentar mi proceso de aprendizaje y las implementaciones realizadas durante mi formación, trabajando diferentes estructuras de datos y conceptos fundamentales de programación.

## Contenido

### Actividad 1 — Diferencia entre arreglos

Implementación de un programa en Java que trabaja con tres arreglos de números enteros.

El programa solicita al usuario dos arreglos de 7 números, calcula la diferencia entre los elementos correspondientes y almacena los resultados en un tercer arreglo. Finalmente, calcula el promedio de las diferencias.

**Conceptos trabajados:**

* Arreglos.
* Ciclos `for`.
* Entrada de datos con `Scanner`.
* Operaciones con arreglos.
* Acumuladores.
* Cálculo de promedios.

### Actividad 2 — Implementación de una pila

Implementación de una estructura de datos tipo **pila (Stack)** utilizando un arreglo, además del uso de la clase `Stack` incluida en Java.

El programa trabaja con operaciones de una pila como agregar y eliminar elementos, consultar su tamaño y determinar el espacio disponible. También utiliza una segunda pila para invertir el orden de los elementos.

**Conceptos trabajados:**

* Estructuras de datos.
* Pilas.
* Arreglos.
* LIFO (Last In, First Out).
* Métodos y clases en Java.
* Generación de números aleatorios.
* Uso de `Stack`.

[Ver Actividad 2](./Actividad_2/)

### Actividad 3 — Árboles y Árboles Binarios de Búsqueda

Implementación de diferentes recorridos sobre árboles binarios y construcción de un **Árbol Binario de Búsqueda (BST)**.

La actividad contiene dos ejercicios principales:

* Construcción manual de un árbol binario y realización de recorridos.
* Implementación de un BST mediante inserción recursiva de valores.

Los árboles se recorren mediante los tres recorridos fundamentales:

* **Preorden:** raíz → izquierda → derecha.
* **Inorden:** izquierda → raíz → derecha.
* **Postorden:** izquierda → derecha → raíz.

En el BST, los valores menores se almacenan en el subárbol izquierdo y los valores mayores o iguales en el subárbol derecho.

**Conceptos trabajados:**

* Árboles binarios.
* Árboles Binarios de Búsqueda (BST).
* Nodos.
* Recursividad.
* Preorden.
* Inorden.
* Postorden.
* Inserción en árboles.
* Referencias entre nodos.
